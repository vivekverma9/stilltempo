# StillTempo 1.0 — Technical Preview

**Status:** Pre-release for experienced testers. The Chrome Web Store submission is undergoing review; this GitHub package is not a Store-approved release.

StillTempo makes Chrome's New Tab page a place that can change with your day. Workspace brings the cool, focused side; Lounge offers a warmer atmosphere. Choose either yourself or set Auto to follow your preferred schedule.

Included in version 1.0:

- Workspace and Lounge with manual and scheduled automatic transitions
- Hitlist tasks, focus timer, browser shortcuts and search
- Curated wallpapers, local photo fallbacks, and optional radio streams
- Weather, optional humour, appearance preferences, and JSON backup/import
- Local storage of tasks and preferences; no account required

### Before you install

This is a manual Developer-mode installation. It does not auto-update. Review the code, declared permissions and [installation instructions](INSTALL.md). The baseline's automated integrity and mocked unit tests passed, but live providers, publication permissions and full installed-Chrome behaviour have not all been independently verified. Expect some online content to be unavailable if an external service is down.

**Download the release asset, not GitHub's auto-generated “Source code” archive.**

### Feedback

Report reproducible problems through GitHub Issues. Include Chrome version, OS, basic steps and expected vs actual results. Do not attach personal browser data or task exports.
