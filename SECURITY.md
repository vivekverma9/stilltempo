# Security and responsible reports

StillTempo is distributed here as a technical preview for people comfortable installing unpacked Chrome extensions.

Before downloading, confirm you're using the official repository shared by the maintainer. Inspect `extension/manifest.json` and source files. Verify the asset SHA-256 shown by GitHub. These steps support transparency and file integrity; **they do not guarantee the software is malware-free**.

**To report a suspected vulnerability privately:** email **thelaughtist@outlook.com** with the subject **StillTempo security report**, or use GitHub's private vulnerability reporting feature if enabled. Avoid posting proof-of-concept details or user data in a public GitHub Issue.

Never share passwords, auth tokens, JSON backups, precise location or other sensitive personal information in issue reports.

Online features rely on external hosts for wallpapers, location/weather, humour and radio. See `PRIVACY.md` for an overview.

The author has not claimed independent penetration testing or Chrome Web Store approval for this preview.
